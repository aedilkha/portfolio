Secure Enterprise Network — Cisco

CCNA-level network for a simulated R&D hub — 48 workstations, €300k budget. A redundant collapsed-core topology with 14 VLANs, a Cisco ASA firewall, a VLAN-based DMZ, least-privilege ACLs and centralized AAA/RADIUS. I also wrote a Python script that auto-generates the access-control lists from the security matrix. Team project at BeCode, where I led the architecture.
